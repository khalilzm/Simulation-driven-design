# shared — 能力注册表与契约

职责：定义跨进程（服务端 / 浏览器 / Agent）共享的能力注册表、工具契约与 schema，作为唯一事实来源。

对应文档：[架构 §9](../docs/architecture.md)、[协议](../docs/protocol.md)。

## 子模块

| 目录 | 职责 |
| --- | --- |
| `contracts/` | 能力注册表、工具契约、事件契约 |
| `schemas/` | `model.json`、日照配置、任务与结果 schema |

## 能力状态（ready 指命名与接口预留，非求解器可用）

| 能力 | 输入扩展 | 输出扩展 | 执行位置 |
| --- | --- | --- | --- |
| `sunlight` | 地点、时序、开口、测点 | 日照时长与可见性 | browser |
| `thermal` | 构造层、热区、气象、负荷、系统与运行条件 | 温度、负荷、舒适性 | 后续按引擎确定 |
| `acoustics` | 声源、接收点、频带、吸声散射属性 | 脉冲响应、混响等 | 后续按引擎确定 |

未实现能力返回 `CAPABILITY_NOT_IMPLEMENTED`，不生成假指标。日照的二值可见性不能直接当作热环境的太阳得热。
