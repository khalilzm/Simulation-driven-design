# benchmarks/sunlight — 日照基准

职责：存放日照求解器基准方案，覆盖固定工况并记录适用精度与性能规模。

对应文档：[架构 §7](../docs/architecture.md)、[roadmap M2](../docs/roadmap.md)。

## 基准用例

- [ ] 无遮挡点（预期满直射时长）。

- [ ] 窗框与顶板。
- [ ] 自遮挡。
- [ ] 时区/朝向与时间步长细化后的误差。
