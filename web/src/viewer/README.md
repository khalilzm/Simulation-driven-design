# Viewer 几何与能力图层

Viewer 展示调用方提供的模型与结果，不选择建筑用途、业务规则或计算引擎。住宅默认采光由住宅控制器决定；模型携带 residentialBrief 元数据也可以查看日照与人流结果。

## 分层与模式

| 显示模式 | 单位 | 几何来源 | 图例 |
| --- | --- | --- | --- |
| usage / 3d | 模型原生单位 | modelRender | UsageLegend |
| daylight | lx | 采光网格 lux | DaylightLegend |
| sunlight | h | 日照网格 hours | SunlightLegend |
| pedestrian | 人/㎡；回放时间为秒 | 密度网格与轨迹 | PedestrianLegend |

`analysisLayers.ts` 注册能力的标签、单位、空状态、完成判断与几何适配器。`AnalysisLegend.tsx` 装配对应图例。Viewer 从注册表生成按钮并显示所选图例；Scene 消费统一的 fills/lines/playback 数据，继续负责 WebGL、相机、资源释放和拾取。

采光与日照使用明确的独立模式，不再以 sunlight 同时表达两种物理量。住宅评价控制器选择 daylight，原优化比较继续选择 sunlight / pedestrian。切换模式不修改模型或结果。未完成或缺失结果不生成该能力的分析网格，也不借用其他能力的数据。

比较视图传入公共日照色标、密度色标和轨迹时间范围，几何适配器与图例都使用这些条件。分析伪彩关闭影响数值阅读的阴影/SSAO/地面效果；usage / 3d 恢复原展示设置。

## 扩展边界

新增可视化能力需注册几何适配器、图例和明确单位，不能依据场景名称切换物理量。没有可视化适配器的能力不自动获得图层；本次没有启用热环境、声学、消防或可达性求解器。

ViewerContent 当前接收每类能力的一个选中结果。工作区多实例计划继续按 moduleId 保存结果，调用方可将所选实例结果交给 Viewer；多实例配置与选择 UI 仍待实现。本次不增加仿真模块数量限制，也不修改分析计划或执行器。

回归验证住宅与普通模型的图层一致性、同时存在采光/日照时按模式独立取值、失败/缺失结果隐藏、统一比较色标、数据不被修改及人流回放隔离。图例另外通过静态 HTML 渲染核对单位、比较色标与失败隐藏。没有进行浏览器 WebGL 截图或交互挂载验证。
