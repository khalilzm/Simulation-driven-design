# web/simulation/sunlight — 日照 Worker

职责：在 Web Worker 内计算给定时段内的**潜在直射日照时长**，非照度、太阳辐射能量、全年采光或实际天气观测日照。

对应文档：[架构 §7](../docs/architecture.md)、[roadmap M2](../../docs/roadmap.md)。

## 输入

- 方案版本、三维遮挡几何、透光开口；顶部/楼板不能遗漏。
- 经纬度、IANA 时区、日期、当地分析时段、建筑朝向；记录转换后的 UTC 时间。
- 室内参考面与窗前控制点、测点间距、参考面高度、时间步长。
- 项目定义的目标时长/区间与目标空间。

## 算法步骤

1. 统一坐标，检查模型与测点。
2. 按时间段采样，计算太阳方向；太阳低于地平线计为无直射。
3. 用固定分析网格建立空间加速结构（可复用 three-mesh-bvh），做射线遮挡查询。
4. 按采样区间实际时长积分，得到每点累计时长与时间段。
5. 按测点代表面积统计空间指标，生成时长图及选定时刻阴影图。

## 基准（验收依据）

无遮挡点、无窗封闭空间、已知遮挡、窗框与顶板、自遮挡；检查时区/朝向与步长细化误差。固定测点、太阳与透光规则下，新增不透明遮挡不应增加日照。
