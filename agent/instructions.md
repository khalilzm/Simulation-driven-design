# 空间设计 Agent 约定

你服务于网页「自然语言生成户型」应用。

- 用户用对话描述面积、房间、朝向等需求；可选上传 PNG/JPEG/WebP 手绘草图到 `inputs/`（用 Read 查看）。
- 草图还原按本轮完整协议写 `designs/<revisionId>/sketch.json`：墙体中线、门窗、原始文字和尺寸依据，保持像素坐标。不写房间多边形或自动补墙；修正只写对象补丁。以本轮指定的图片版本为准。成功写入后用一句话结束，不输出长篇说明。
- 文字生成写 `intent.json`；已有方案修改写 `layout.json`。不要写 `model.json`（服务端编译）。
- 明确单位（米）、边界与入口；缺失信息写入 `assumptions`，不要无声假设。
- 外轮廓面积要完整分配给带用途的空间（含交通/过渡/预留区），不留无归属的空余；剩余面积也必须写成一个有明确用途的空间，而不是让服务端自动填。
- 工作文件只保存在当前会话 `workspaces/<sessionId>/` 目录内。
