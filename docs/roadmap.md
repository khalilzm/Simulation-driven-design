# 实施顺序与验收

本项目按可验证增量推进。架构预留不等于功能已完成。

## M0：项目与架构基线（本次）

- [x] 建立独立项目目录和可启动 Express。
- [x] 网页对话入口及 Codex / Claude 提供方选择。
- [x] CLI 命令与输出事件适配、指定会话恢复、消息保存。
- [x] 架构文档、SVG 架构图、Mermaid 架构及时序源文件。
- [x] 日照、热环境、声环境能力状态注册。
- [ ] 使用实际登录的两种 CLI 分别完成模型调用验收。

验收：依赖安装、语法检查、适配器契约测试和 HTTP/UI 冒烟。CLI help 检查不等于实际模型调用成功。

## M1：图纸到可查看方案

- DXF 上传和会话内文件登记。
- Agent 解析、必要信息补齐与解析结果确认。
- model.json 校验、固定构件及编辑权限。
- 生成多份候选方案，保存新版本，显示平面预览。

验收：单位正确、固定结构保留、房间边界有效、门洞宿主关联正确；原文件不被覆盖。

## M2：独立浏览器日照分析

- 确定太阳位置算法、坐标/时区约定、测点生成与 BVH。
- Web Worker 数值计算，主线程显示进度与分析图。
- 逐时可见性、时长、时间段、空间指标和图像导出。
- 无窗、无遮挡、遮挡、顶板、朝向/时区等基准。
- 时间和空间采样细化，以及独立参考结果对照。

验收：不调用 Agent 也能对标准方案完成可复现的日照分析；记录适用精度与性能规模。

## M3：Agent—浏览器闭环

- Agent 文件交接、任务校验、浏览器领取和结果回传。
- 恢复对应 CLI 会话，数值与图像证据诊断。
- 修改方案、重新计算、比较前后变化，满足约束并保存原因。
- 取消、断线、重启、重复回传、旧结果与预算限制。

验收：从一次对话触发生成与优化；相同工况下确有性能改善，并且没有破坏固定条件。Agent 读图能力逐提供方验证。

## M4：按需求启用 ready 项

- 热环境明确热区、材料与系统输入后选择引擎。
- 声环境明确室内混响/声场或隔声子能力后选择引擎。
- 复用会话、版本、任务与证据契约；按成本与兼容性确定执行器。

跨场景复用时保留各领域专属 schema，不将日照几何假设直接当热工或声学假设。
