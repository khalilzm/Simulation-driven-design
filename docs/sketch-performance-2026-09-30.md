分析最近两次真实用户运行，均使用 Cursor `composer-2.5`。下述时间均为北京时间。

## 数据来源与口径

- `workspaces/<sessionId>/session.json`：用户请求时间与响应保存时间，作为服务端总耗时边界。
- `workspaces/.cursor-agent-store/agents.ndjson`：仅用于把工作目录关联到 Agent。
- 同目录 `runs.ndjson` 的 `startedAt` / `endedAt`：每轮 SDK 运行耗时。
- 同目录 `run_events.ndjson`：根据工具调用和助手公开输出判定识别、格式修正、几何修正、视觉复核阶段；按 `runId` 聚合，不重复累计更新记录。
- `designs/rev-0001/sketch-raw.json`、叠加图的文件时间：辅助确定首次识别完成与首次编译结束的时间边界。

旧版未记录上传请求、图片处理和各程序阶段的起止时间，不能把上传到发起生成之间的间隔当作图片处理耗时。SDK 运行时间包含模型服务等待、工具执行与输出，不等于纯推理时间。SDK 运行之外的时间只能合并归为鉴权、创建/恢复、清理、编译与文件操作，无法进一步精确拆分。表中的“其他”是总耗时减各轮 SDK 耗时，不遗漏也不重复累计。
