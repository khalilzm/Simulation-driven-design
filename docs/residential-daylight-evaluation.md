# 住宅室内采光评价

住宅主流程采用标准 CIE 阴天天空的采光系数计算。Radiance daylight-factor recipe 包含天空漫射光、窗玻璃透射与室内反射（-ab 4）。采光系数 DF 是室内水平照度与无遮挡室外水平照度的百分比；照度 lx = DF / 100 × 室外参考照度。第一版不依赖地点、日期、太阳方向，也不是实际天气预测或全年采光评价。

## 生成前需求

节点 room.daylight 设置 enabled、minIlluminanceLux、minAreaRatio、priority。全局 brief.daylight 设置 outdoorIlluminanceLux、评价平面高度、网格间距、墙／顶／地反射率与窗可见光透射率。默认 10,000 lx、0.75m 高、0.5m 网格、反射率0.5／0.8／0.2、透射率0.65；房间默认目标300 lx、50%面积。均可编辑，属于方案比较参数，非规范认证。

旧节点图保留原日照记录。旧房间启用状态、面积比例与优先级用于初始化采光目标，但小时阈值绝不换算为照度，界面提示核对新的300 lx初始目标后保存。旧测点设置保留。Agent主流程只接收采光需求；冻结文件 generation-brief.json 和 daylight.json 绑定生成版本。

## 几何与评价

保留原轮廓、屋顶、固定承重墙、生成隔墙、真实窗洞和墙厚。窗洞添加Glass材质；门按关闭不透明处理。阳台沿用当前封闭空间模型。室内地面、墙面与顶面使用编辑的反射率；未提供外部建筑遮挡时明确提示。第一版统一窗透射率，不建窗框细节、家具和实测材料。

每个房间按精确净边界生成水平网格，结果以网格面真实面积计权，输出平均／最小／最大照度、平均DF、达到该房间照度阈值的面积比例。按原间距和一半间距各算一次，平均照度变化超过max(15 lx,5%)、面积比例变化超过2个百分点或跨越目标判定时标记待确认。覆盖率须98%～102%，缺少结果或未收敛不能判定达标。两级稳定是数值检查，不是严格误差界；不无限加密，保留30000测点预算与180秒进程超时。

## 持久化与界面

GET／POST /api/designs/:sessionId/:revisionId/residential-evaluation 读／运行采光评价。新结果保存于 residential-daylight-evaluation.json；历史 residential-evaluation.json 直射日照记录独立保留。缓存哈希包含模型、完整冻结需求、工况及引擎版本。取消、失败或服务重启不删除几何候选。

生成后自动计算；评价表显示lx、DF%、实际达标面积比例、覆盖率和采样状态。热力图存储独立lux数组，固定0～1000 lx色标，超过上限饱和但评价使用原值。选择节点或房间可定位结果。软目标未满足单独计数；无硬目标失败不代表所有软目标通过。

本阶段完成一次采光评价，不自动反馈重排，不降低用户目标。后续可基于房间达标面积比例、照度缺口和采样可信度驱动候选策略与重排。
