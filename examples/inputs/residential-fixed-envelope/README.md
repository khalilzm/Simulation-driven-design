# 住宅固定轮廓测试图纸

`residential-fixed-envelope.dxf` 为 AutoCAD 2010 ASCII DXF，模型空间，单位毫米，1:1。它是最小生成流程的合成测试输入，不是结构设计或施工图。

## 几何与图层约定

原点为外轮廓西南角，X 向东、Y 向北。外轮廓为 12000 × 9000 mm，包络面积 108 m²（非套内使用面积）。所有墙厚 200 mm。图纸不预设房间、可变隔墙或功能分配。

| 图层 | 实体与语义 |
| --- | --- |
| FIXED_OUTLINE | 1 个闭合 LWPOLYLINE，表示建筑外墙外表面的固定包络；它不是一堵连续实体墙，入口与窗洞处仍保持闭合 |
| FIXED_LOAD_BEARING | 12 个闭合 LWPOLYLINE，表示实际墙体占地；10 段外围墙体和 2 段内部墙体；门窗洞已从外围墙体中扣除 |
| FIXED_ENTRANCE | 1 个闭合 LWPOLYLINE，表示北侧入户洞口占地，x=5500～6500，y=8800～9000，净宽 1000 |
| FIXED_WINDOW | 5 个闭合 LWPOLYLINE，表示穿过外围墙厚的窗洞占地；不是房间、障碍实体或可通行门洞 |
| SYMBOLS | 门扇开启示意与窗线，仅供显示，不参与轮廓及障碍提取 |
| ANNOTATION | 标题、尺寸、编号、北向及说明，仅供显示，不参与几何提取 |

固定实体有 `SDD_FIXED` XDATA，含 ID、类型及辅助属性。图层与实体几何是主要导入依据；不能依赖标注文本恢复约束，也不能将显示符号视为墙体。

## 固定要素

- 入户 D1：北侧，宽 1000 mm，高 2100 mm；门弧为向内开启示意。
- 南侧 W1：x=1000～2800，宽 1800 mm。
- 南侧 W2：x=5000～7000，宽 2000 mm。
- 南侧 W3：x=9200～11000，宽 1800 mm。
- 北侧 W4：x=1500～3300，宽 1800 mm。
- 北侧 W5：x=8700～10500，宽 1800 mm。
- 全部窗：窗台高 900 mm，窗洞高 1200 mm，窗顶高 2100 mm；这些是测试假设，已写入 XDATA。
- 内部承重墙 S11：x=4300～4500，y=200～3000。
- 内部承重墙 S12：x=4300～4500，y=5200～8800。
- 两段内部墙之间保留 2200 mm 净通道；这不是预设走廊功能。
- 墙高测试假设为 2800 mm，已写入 XDATA；顶部楼板、玻璃材料、地点和日期不由这份二维图纸定义。

## 使用范围与检查

已通过 ezdxf 重新读取与 audit（零错误、零修复）。PNG/SVG 预览的固定几何来自保存后重新读取的 DXF。

网页支持通过「上传 DXF」直接解析本文件并保存为可重新打开的方案版本，Viewer 支持二维固定构件配色与三维门窗洞口显示。导入器按上述四个固定图层读取模型空间闭合多段线，墙体和洞口须为矩形占地（允许旋转）；支持毫米和米，统一换算为米。不支持的固定构件几何或缺失单位会明确报错；SYMBOLS 与 ANNOTATION 不作为障碍物导入，匹配的门弧用于确定开启方向。

导入后的底图尚未生成房间，不能直接进入房间仿真优化。本文件不包含家具、管井或其他固定要素类型。
